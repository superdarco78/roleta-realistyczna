# 🤝 Zasady zachowania / Code of Conduct

**PL.** W tym projekcie wszyscy są mile widziani. Piszemy uprzejmie, pomagamy początkującym
i rozmawiamy o sprawie, nie o ludziach. Obraźliwe, nękające lub spamowe wpisy będą usuwane,
a ich autorzy mogą zostać zablokowani.

**EN.** This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, help beginners and keep discussions about the work, not the person.
Abusive, harassing or spam content will be removed and its authors may be blocked.

Zgłoszenia / Reports: [@superdarco78](https://github.com/superdarco78) przez [prywatne zgłoszenie](https://github.com/superdarco78/roleta-realistyczna/security/advisories/new) lub issue.
