# 🙋 Jak pomóc / How to help

**🐞 Błąd?** [Zgłoś go](https://github.com/superdarco78/roleta-realistyczna/issues/new/choose): napisz wersję karty (np. v22), model rolety/silnika i dołącz zrzut ekranu.

**💡 Pomysł?** [Zaproponuj funkcję](https://github.com/superdarco78/roleta-realistyczna/issues/new/choose).

**🌍 Tłumaczenie?** Teksty są w [`translations/`](translations) (`pl.json`, `en.json`). Skopiuj `en.json`, przetłumacz i wyślij.

**🧑‍💻 Kod?** Źródła są w `src/`. `npm install`, potem `npm run check` (lint + testy + budowanie `dist/`). Nie edytuj `dist/` ręcznie – powstaje z `src/`.

---

**🐞 Bug?** [Report it](https://github.com/superdarco78/roleta-realistyczna/issues/new/choose) with the card version, your blind/motor model and a screenshot.
**💡 Idea?** [Request a feature](https://github.com/superdarco78/roleta-realistyczna/issues/new/choose).
**🌍 Translation?** Texts live in [`translations/`](translations). Copy `en.json`, translate it and send it.
**🧑‍💻 Code?** Sources are in `src/`. Run `npm install`, then `npm run check` (lint + tests + build). Never edit `dist/` by hand – it is built from `src/`.
