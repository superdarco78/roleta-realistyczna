# 🔒 Bezpieczeństwo / Security

Karta działa tylko w przeglądarce, w Twoim Home Assistancie. Nie wysyła danych na zewnątrz. Jedyny wyjątek: gdy nie masz encji pogody, pobiera pogodę z Open-Meteo dla lokalizacji domu (bez klucza i bez konta).

Znalazłeś problem z bezpieczeństwem? Nie pisz go publicznie. Zgłoś przez **Security → Report a vulnerability** w tym repozytorium.

---

The card runs only in your browser inside Home Assistant and sends no data out, except fetching weather from Open-Meteo (no key, no account) when you have no weather entity. Report security issues privately via **Security → Report a vulnerability**.
