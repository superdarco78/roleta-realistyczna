<a name="faq"></a>
### <a name="i51" href="#i51"><img src="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/v23/ikony/help-circle.png" height="26" align="absmiddle"></a> Questions et problèmes

<br>

#### <a name="i52" href="#i52"><img src="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/v23/ikony/alert-circle-outline.png" height="22" align="absmiddle"></a> La carte n’est pas dans « Ajouter une carte »

Recharge la page : **Ctrl + Maj + R**. Sur téléphone, rouvre l’application HA. Puis tape **Roleta** dans la recherche.


<br>

#### <a name="i53" href="#i53"><img src="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/v23/ikony/alert-circle-outline.png" height="22" align="absmiddle"></a> L’animation va plus vite ou plus lentement que le store

Ouvre l’éditeur, section **Ruch i kalibracja** (mouvement), clique sur **Kalibruj automatycznie**. La carte mesure le temps seule.


<br>

#### <a name="i54" href="#i54"><img src="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/v23/ikony/alert-circle-outline.png" height="22" align="absmiddle"></a> Pas de météo derrière la vitre

Ouvre l’éditeur, section **Zaawansowane** (avancé), source météo **auto** ou **internet**.


<br>

#### <a name="i55" href="#i55"><img src="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/v23/ikony/alert-circle-outline.png" height="22" align="absmiddle"></a> Le store va dans le mauvais sens

Ouvre l’éditeur, section **Zaawansowane** (avancé), active **Inverser la position**.


<br>

#### <a name="i56" href="#i56"><img src="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/v23/ikony/alert-circle-outline.png" height="22" align="absmiddle"></a> Le capteur de fenêtre ne marche pas

Ouvre l’éditeur, section **Okno** (fenêtre). Choisis le capteur de chaque battant et **entrouvert** ou **ouvert**.
